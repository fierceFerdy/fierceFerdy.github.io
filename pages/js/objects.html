Class + constructor

A class is like a template/blueprint. You can create multiple similar objects from it. You can compare it to a printed form which you can fill in. Yet, classes have way more functonalities. It's code after all!

One important distinctionDistinction: A clear difference: Objects are actual data. Classes are templates used to create those objects.

You define a class by typing class and then the name in PascalCasing. This is an exception to the usual camelCasing rule and it is widely adoptedAdopted: It's the standard, it's what people do to make it easier..

Since you need to make objects from this template, you need to be able to fill in data. That's what the constructor is for. The constructor is a special function which you can use to receive data when making an object and to then assign those values to (earlier defined) propertiesNL: eigenschappen.

Properties are kind of like variables. They hold data but they are accessed differently. All properties are added to this object.

Getters and setters

You use getters to get data and setters to set/change data. You create them almost like how you create a function. Additionally, just like with functions, you can also do other things in these getters and setters. Maybe you want to format a name or check a value before changing it.

One thing we can do better is make use of the fact that getters and setters are properties as well. This means they're like innerHTML and can actually use the same 'word' both for getting and setting!

Since we'll be using 'fname' as a getter and setter we need to change the name. Putting a underscore in front of it is widely adopted.

Methods

Methods are functions which are properties of an object. They are used to give objects functionality. You can create them in a similar way as getters, setters and functions but instead of using get, set or function you just write the name of the method.
