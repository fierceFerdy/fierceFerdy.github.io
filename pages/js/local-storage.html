LocalStorage

Usually we save data in variables. But, variables disappear when you refresh the page. localStorage however allows you to save data inside the browser so it can still exist later.

You can use localStorage to (amongst other things):

  • Save settings
  • Remember usernames
  • Store theme preferences
  • Save simple app data
  • Keep data after refreshing the page

ELI5

Variables are like writing on a whiteboard. When the page reloads, the whiteboard gets erased. localStorage however is more like putting the information in a locker. Even if you leave and come back later, the data is still there.

Comparison

When you compare localStorage to JSON, localStorage is like a simple key-value store where both the key and the value are strings whilst JSON is a whole file of data. But the biggest difference between the two might be that localStorage is saved locally in the user's computer, making it specifically for the user. JSON however is more something for global data which can be available to every user.

Variables localStorage JSON
Persists after refresh? No Yes Depends where stored

Saving data

You can save data using localStorage.setItem(). The function accepts two values, the name of the value (key) and the value itself. Try it out!

Now that you've saved your name, let's check it out! Open the DevTools, switch to the "Application" tab and in the sidebar open "Local Storage" under "Storage". You should see your saved name there.

Lots of websites store data in your browser and not only using localStorage, as you can see. You can always see what a website's up to using the DevTools. Do you recognise what else is stored in there right now?

Getting data

Of course, using the DevTools is not the only way to see the data that's been saved. You can always get saved data back using localStorage.getItem(). Can you figure out how to get your data?

Removing data

And lastly, if you no longer need something, you can remove it using localStorage.removeItem()

JSON to the rescue

To properly save objects and arrays, we convert them to JSON first. As you can see, JSON is not only used in files. JSON is simply a text format for structured data.

Now the object becomes a string that localStorage can store.

Converting it back

When you get the data back, it will still be a string. You can convert it back into a real object using JSON.parse().
