JavaScript Summer Bootcamp

This bootcamp is meant for students who have already seen JavaScript, but still struggle to solve exercises independently. The goal is not to build big projects as quickly as possible. The goal is to learn how to think like a programmer.

You will practise reading code, predicting output, testing, finding bugs and building small programs. You are allowed to work slowly. You are allowed to make mistakes. But you are not allowed to start typing without thinking first.

How to work

For every exercise, use the same method:

  1. Analyse the problem.
  2. Write in words what your program should do.
  3. Only then write code.
  4. Test with multiple examples.
  5. Improve your code if something is wrong.

You may only start programming after you have filled in the analysis. This is not extra work. This is learning how to program.

How to analyse

Answer these questions before every larger exercise.

  • What information do I get?
  • What information should my program show?
  • Which variables do I need?
  • Does my program need to make a choice?
  • Do I need conditional logic?
  • Which steps should my program follow?
  • Which test values will I use to check if my program works?

What to submit

For every week, create a folder. When finished, upload the full folder on smartschool. For week 1, create:

recovery-bootcamp/
└── week-01/
	├── exercise-01/
	├── exercise-02/
	├── exercise-03/
	├── exercise-04/
	├── exercise-05/
	└── mini-challenge/

Every exercise should contain at least:

  • an HTML file
  • a JavaScript file
  • your analysis as a comment at the top of your JavaScript file:

Hint: create a html and js file that are ready to start from and copypaste them into every folder.

Some rules during this bootcamp

  • Make clean, easy to read code.
  • Test every exercise with multiple values.
  • Do not just copy code. Type manually and try to understand what it does.
