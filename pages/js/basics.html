JavaScript 101 /basics

When working with JavaScript, the console is just as important as the editor. It allows you to see the output of your code, debug errors, and interact with your program in real-time. The console is your friend, don't forget that.

  • As a first exercise, log something in the console: console.log("Hello, world!");
  • Press CTRL + SHIFT + Enter to run your code.

Variables

Variables are like containers for storing data. They allow you to give a name to a value and use that name to refer to the value later in your code. In JavaScript, you can declare a variable using the "var", "let" and "const" keywords. But, in class we will only use var in order to keep it easier.
