Week 1 - Thinking Like a Programmer

This week is mostly about understanding code. You will not immediately write large programs.
First, you need to learn how to predict what code does.

Topics

  • variables
  • changing values
  • console.log()
  • comparisons
  • conditions: if, else if and else
  • finding bugs

Goals

By the end of this 'week', you can:

  • explain step by step what a program does
  • predict the output of simple code
  • recognise and fix mistakes
  • write a small program with conditions

Exercise 3 - Find the Bug

Each program contains at least one mistake. For each one, write down:

  • what the mistake is
  • why it is wrong
  • how to fix it

Bug 1

var age = 18;

if (age = 18) {
console.log("Adult");
}

Bug 2

var score = 45;

if (score >= 50) {
console.log("Passed");
else {
console.log("Failed");
}

Bug 3

var username = "ferdy";

if (userName == "ferdy") {
console.log("Welcome");
}

Bug 4

var number = 7;

if (number > 10) {
console.log("Big");
} else if (number < 10) {
console.log("Small");
} else if (number == 7) {
console.log("Seven");
}

Bug 5

var isStudent = "yes";

if (isStudent == yes) {
console.log("Student price");
}

Hint: Pay close attention to capital letters, brackets, strings and the difference between = and ==.

Exercise 5 - Write Your First Programs

Now you write small programs yourself. Fill in the analysis before each task.

Program 1 - Age

Create a variable age. Show:

  • "Child" if the age is lower than 12
  • "Teenager" if the age is lower than 18
  • "Adult" if the age is lower than 65
  • "Senior" from 65

Program 2 - Two Numbers

Create two variables: numberOne and numberTwo. Show which number is the largest. If they are equal, show "Equal".

Program 3 - Score

Create a variable score. Show:

  • "Invalid score" if the score is lower than 0 or higher than 100
  • "Failed" if the score is lower than 50
  • "Passed" if the score is lower than 70
  • "Good" if the score is lower than 85
  • "Excellent" from 85
Hint

Use else if. Check your conditions in the correct order.

Mini-challenge - Cinema Ticket

Create a program that calculates the price of a cinema ticket.

Data

Your program uses these variables: 

var age = 16;
var isStudent = "yes";
var price = 0;

Rules

  • Children younger than 12 pay €8.
  • Students pay €10.
  • Adults pay €14.
  • Seniors from 65 pay €9.

Then show: 

Ticket price: €10

Required

  • Use if, else if and else.
  • Use a variable called price.
  • Test with at least five different ages.
  • Test at least one student and one non-student.
Hint 1

First decide the price. Only show the message at the very end.

Hint 2

Some rules are more important than others. A child who is also a student should still get the child price.

Hint 3 
if (...) {
price = ...;
} else if (...) {
price = ...;
} else if (...) {
price = ...;
} else {
price = ...;
}

console.log("Ticket price: €" + price);
