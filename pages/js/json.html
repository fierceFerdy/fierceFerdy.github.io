JSON

JSONJavaScript Object Notation is a format for storing and transporting data. It is often used when data is sent from a server to a web page and pretty much everywhere else. No matter what IT field you end up working in, you will work with JSON.

Contradictory to its name, JSON is a text format that is completely language independent but uses conventions that are familiar to programmers of the C-family of languages, including C, C++, C#, Java, JavaScript, Perl, Python, and many others. These properties make JSON an ideal data-interchange language. The best of all; it's easy for humans to read and write, and easy for machines to parse and generate.

The advantages of using JSON

  • Data is easily accessible and readable for multiple people
  • You don't need a database (even though it's most often used in combination)
  • It can be quicker than a database
  • When you have lots of data its cleaner to split up than doing it in your code (js/php/..)
  • You can use the data for different languages (you can export from one and import in another)
  • Since it's broadly used, a lot of apps/APIs export data as json
  • It's cleaner than other similar alternatives like XML

JSON syntax

JSON looks very similar to JavaScript objects and arrays.

Getting data from a JSON file

To get data from a JSON file, you can use the fetch() function. This function returns a promisePromise: An object representing the eventual completion or failure of an (asynchronous) operation. that resolves to the response of the request. You can then use the .json() method to parse the response as JSON.

ELI5

Imagine you have a box (the JSON file) that contains a letter (the data). You want to read the letter, but you can't open the box. Instead, you have to ask a friend to fetch the letter for you. The fetch() function will go to the box, get the letter, and then give it to you. Once you have the letter, you can read the letter and understand the 'data' inside.

When you get this type of data, it's basically just a string. You can convert it back into a real object using JSON.parse().

Creating a JSON file

To create a JSON file, you can use the JSON.stringify() method to convert a JavaScript object into a JSON string. You can then save this string to a file or send it to a server (we will not be doing this in this course).

Save to a file

To save a JSON string to a file, you can use the Blob object and the URL.createObjectURL() method to create a downloadable link.
