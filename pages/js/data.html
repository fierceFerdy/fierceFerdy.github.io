Variables

Variables are like boxes for storing data. You slap a big label on them to know what's inside and that's that.

Variables allow you to give a name to a value and use that name to refer to the value later in your code. In JavaScript, you can declare a variable using the "var", "let" and "const" keywords. But, in class we will only use var in order to keep it easier.

You create a variable like so: var myNum = 2;. If you then want to either read or change the content of the variable you can just type the name, without writing 'var' again.

Datatypes

There are several basic "datatypes" in JavaScript. In most cases you don't have to tell the computer what type of data you're using, it figures it out for you.

Naming conventions

Now that we've started naming things, it's important to follow certain conventions/rules to make your code more readable and maintainable. Here are some common guidelines:

  • Use camelCasing (e.g., myVariableName) - easier to read than myvariablename.
  • Choose descriptive names that convey the purpose.
  • Avoid using special characters.

By following these conventions, you can make your code easier to understand for yourself and others who may read it in the future.
