Selecting elements

Using document.getElementById() we can select an element in our document that has a specific id. Then we can manipulate that element. Each editor will have their own custom body which you can use to do all sorts of fun stuff with!

getElementById() is a very handy function that you will use a lot. You usually don't just put everything in the body but in a specific element!

Advanced methods

querySelector() will let you select the first match of any element that mathes your selector. This works exactly like selecting elements in CSS!

Some examples:

  • document.querySelector('.block');
  • document.querySelector('a.btn');
  • document.querySelector('#videos .toggle');

querySelectorAll() this will now select ALL elements that match. You might want to select all buttons for example so you can add an eventListener.
