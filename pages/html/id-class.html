Kenmerken van een id: - Is uniek, je mag er maar één per pagina gebruiken - Wordt gebruikt om een specifiek element te identificeren - In CSS wordt een id aangeduid met een hekje (#) gevolgd door de naam van het id - In JavaScript kan een id makkelijk worden gebruikt om een individueel element te selecteren Kenmerken van een class: - Kan meerdere keren op een pagina worden gebruikt - Wordt gebruikt om een groep elementen te identificeren die dezelfde stijl of functionaliteit delen - In CSS wordt een class aangeduid met een punt (.) gevolgd door de naam van de class - In JavaScript kan een class worden gebruikt om meerdere elementen te selecteren die dezelfde class hebben
